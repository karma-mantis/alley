# alley
A bowling game I made. The game is supposed to give the feeling of those old smartphone games, and adding an eerie moment as the game progresses.
It is my first time finishing and uploading a html game to itch.io so I don't think it's that good, but i tried to do my best. I'm a big fan of the older internet and it's technology, how everything there seemed so still. It always hits me with a small wave of nostalgia, I remmeber how I used to play that smash hit game on my mom's phone and I always had a blast. The game can be found on https://cuerr.itch.io/alley and here are the assets I have used.

some things i want to note are:
-- for the ball, I have used a free asset from unity, and changed it a little using the divide option in ibis paint x, layering it on top of a flat blue ball.

-- for the background, I used the crystal mountains biome in minecraft from the "better end" mod. I have spent some time wondering how to make it look good
